# ₿ BTC Tracker

Eine minimalistische, mobile-optimierte Bitcoin-Preis-Tracker-App mit 5 Währungen.

## Features
- 5 Währungen: EUR, USD, GBP, JPY, CHF
- PWA-ready für iOS (installierbar)
- Offline-fähig mit localStorage-Cache
- Automatische Updates alle 60 Sekunden
- Glassmorphism-Design

## Installation
Einfach `index.html` im Browser öffnen oder auf GitHub Pages hosten.

## Nutzung
- Klicke auf "Aktualisieren" für manuelle Updates
- Auf iPhone: "Zum Home-Bildschirm hinzufügen" für PWA-Erlebnis
